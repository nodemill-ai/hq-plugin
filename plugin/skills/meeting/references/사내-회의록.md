# 사내 회의록 템플릿 (안건 노트 = 회의록)

같은 `회의록.md` 하나가 미팅 전에는 안건 노트 (`status: 준비`), 정리 뒤에는 회의록 (`status: 완료`). 원본 = 2026-11-04 주간 미팅 노트 (사용자가 고친 구조).

## 쓰는 규칙 (이 절은 노트에 넣지 않는다)

- **노트에는 아래 "템플릿" 블록 안의 내용만** 쓴다. 이 절의 설명 · "미팅 전에 각자 적는다" 같은 안내 문구 · HTML 주석을 노트에 넣지 않는다.
- **구분**: 큰 절 (`## 지난 액션` · `## 안건` · 안건 블록마다 · `## 기타` · `## 다음 미팅으로 넘김`) 사이에 `---` 한 줄. 안건 블록 안의 칸은 굵은 라벨 (`**상세**` · `**논의**` · `**결정**` · `**액션**`) — 제목 단계 (`###`) 를 쓰지 않는다.
- **머리 3줄** (`**일시**` · `**참석**` · `**녹음**`) 은 줄마다 빈 줄로 띄운다 — 붙여 쓰면 Markdown 이 한 문단으로 합쳐 hq 에서 한 줄로 보인다.
- **안건 표** = `# · 안건 · 기안` 3칸만. 안건 칸 = 아래 블록 제목으로 가는 링크 `[제목](#<앵커>)`. 목적 · 자료 · 선택지는 표가 아니라 그 안건 블록의 `**자료**` · `**상세**` 에.
- **앵커** = 블록 제목 `## N. 제목` 의 GitHub 규칙 (github-slugger): 영문 소문자 → 글자 · 숫자 · 공백 · `-` · `_` 밖 문장부호 (`.` `·` `,` `(` `)` `/` `?` …) 를 지움 → 공백마다 `-` (연속 공백 = 연속 `-`). 한글은 그대로.
  - `## 1. 미팅 방식 소개` → `#1-미팅-방식-소개`
  - `## 2. hq 소개 · 대표 온보딩` → `#2-hq-소개--대표-온보딩` (`·` 가 빠져 공백 둘 → `--`)
  - `## 10. 이지민 지분 처리` → `#10-이지민-지분-처리`
  - 안건 제목 앞 번호 `N.` 때문에 앵커가 겹치지 않는다. 안건 번호 · 제목을 바꾸면 표의 링크도 같이 바꾼다.
- **이름** = hq 구성원 전체 이름 (`listMembers` 의 `name` — 예 `이재완` · `조성우`). 성 빼기 · 직책 · 별명 · 영문 아이디 금지. (멘션 알림은 hq 에 없다 — 이름만 적는다.)
- **링크** — 본문에 나오는 hq · 위키 · Drive · 외부 자료는 전부 링크로, 절대 URL (회의록은 Drive 에서도 열린다 — 상대 경로는 Drive 에서 깨진다):

  | 대상 | 링크 | 글자 |
  |---|---|---|
  | hq 태스크 | `https://hq.nodemill.ai/tasks?task=HQ-0057` | `HQ-0057` (또는 할 일 이름) |
  | 로드맵 | `https://hq.nodemill.ai/tasks/roadmap?roadmap=<id>` (`listRoadmaps` 의 id) | `로드맵 · <이름>` |
  | 위키 | `https://hq.nodemill.ai/wiki?path=<경로>` (`getWikiPage` 의 `hqUrl`) | `위키 · <제목>` |
  | 사용법 | `https://hq.nodemill.ai/guide` | `hq 사용법` |
  | 태스크 보드 | `https://hq.nodemill.ai/tasks` | `태스크 보드` |
  | 미팅 | `getMeeting` · `listMeetings` 의 `hqUrl` | `YYYY-MM-DD 주제` |
  | Drive 파일 · 폴더 | `webViewLink` | 파일 이름 |
  | 외부 | 원래 URL | 이름 (URL 만 있으면 URL 그대로) |

  키 범위는 양끝을 링크 (`[HQ-0057](…) ~ [HQ-0060](…)`). 지어낸 URL · id 금지 — 조회로 못 찾으면 링크 없이 이름만.
- **준비 때**: 안건 블록의 `**논의**` · `**결정**` 은 `-` 한 줄 · `**액션**` 표는 빈 행 1개. `**상세**` 는 기안자가 준 내용 (없으면 `-`) — 결정이 필요한 안건은 선택지 (A / B) 까지. `## 기타` 는 `### 기타 1.` 빈 틀 1개.
- **정리 뒤** (`clova-변환.md`): 안건마다 논의 · 결정 · 액션을 채운다. 논의가 없으면 `- 없음` · 결정 없으면 `- 보류 — <이유>` · 공유만 한 안건은 `- 공유`. 액션 표는 **행 ≥ 1** (없으면 `액션 없음 — <이유>` 1행). 안건에 없던 내용은 `### 기타 N. <짧은 제목>` 블록 (논의 · 결정 · 액션 — 기안 · 자료 · 상세 없음). 쓰이지 않은 `### 기타 1.` 빈 틀은 지운다 (기타가 하나도 없으면 `## 기타` 아래 `- 없음`).
- **지난 액션** 표: 액션 칸 = 할 일 이름 · 키 칸 = 키 링크 · 피드백 = 결론 1줄 (+ 이어지는 안건이 있으면 ` → [안건 N](#<앵커>)` · 기타로 갔으면 ` → 기타`). 논의가 길면 표 아래 `**논의**` 에 `- [HQ-0000](…) <할 일>: 2~4줄`. 첫 주간 미팅이면 `없음 (첫 미팅)` 1행.
- **액션 표** 칸: 할 일 · 담당 (이름) · 마감 (`YYYY-MM-DD` · 또는 `마감 미정 (<원문>)`) · 구분 (`새 태스크` · `기존 갱신 → <상태>` · `종료 → done`) · 키 (링크 · 담당이 없으면 `(담당 정해지면)`).
- **사외 미팅**은 이 템플릿이 아니다 → `회의록.md`.
