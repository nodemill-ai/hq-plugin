# 고정비 · 금액 읽기

- `listCostItems { month? }` (기본 이번 달 · `includeArchived: true` = 해지 포함). 항목마다 `amount` 를 말한다:
  - `kind: "recorded"` = 기록 합계 `totals` (통화별 그대로 — USD 구독을 원화 카드로 결제하면 KRW · 환산 없음)
  - `"expected"` = 아직 기록 없음 · 예상일 뿐
  - `"live"` = 실시간 현재 금액
  - `"none"` = 그 달 청구 기록 없음 · `"no-billing"` = 매년 항목의 결제월 아님
  - `recordedAmount` 는 옛 필드 — 쓰지 않는다. 결제일 = `billingDate` · `nextBillingDate`.
- **AWS (`liveSource: "aws"`)**: 예상 금액을 쓰지 않는다. 이번 달 = `amount.live` (`asOf` = AWS 기준 시각) — 하루 1회 가져온 현재까지 실제 지출 (표시용 · 장부 합계와 다르다고 말한다) · `null` = 아직 안 가져옴 · `liveSources[].stale` = 36시간 넘게 갱신 안 됨. 지난 달 = 다음 달 초 카드 결제 기록 (그 달 행으로 귀속 · `getCostSummary` 는 결제 날짜 기준이라 한 달 어긋난다고 말한다). 붙이기 · 떼기 = `updateCostItem { costItemId, liveSource: "aws" | null }` (사용자가 말했을 때만).
- **합계 · 추이**: `getCostSummary { month?, months? }` ("최근 6개월" → `months: 6`) — 확인된 기록만 · 환산 없음 · 분류별 `byCategory` · 반복 항목에 안 묶인 것 = `other`.
- **새 항목**: 사용자가 말했을 때만 `createCostItem { name, category (infra · ai · saas · other), cycle (monthly · yearly), billingDay, billingMonth? (yearly), expectedAmount, currency, paymentMethod, card?, plan?, note?, liveSource? }` — 정액 구독은 `expectedAmount` 필수 · AWS 는 빼고. 빠진 필드는 한 번에 묻는다.
- **해지 · 변경**: `updateCostItem { costItemId, archived: true | false }` (기록은 남는다 · 해지는 이름 확인 뒤) · 금액 · 결제일 · 카드도 같은 도구 (바꿀 필드만).
- 결제 뒤 "이번 달 기록해줘" → 등록 흐름으로 `costItemId` 를 묶어 `createExpense` (금액은 확인 — 예상과 다를 수 있다).
