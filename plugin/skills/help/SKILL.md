# hq 사용법 안내

사용법 원본은 hq 서버의 문서 하나다 — 이 스킬에 내용을 외워 두지 않는다. 매번 hq MCP 서버 (`hq`) 의 `getGuide` 를 **인자 없이** 한 번 호출해 읽는다 (반환 `{ markdown, webUrl }` · 배포된 hq 버전 기준이라 기능이 바뀌면 문서도 같이 바뀐다).

## 절차

1. `getGuide` 호출 → `markdown` 에서 질문에 맞는 섹션 (`##` · `###` 제목) 을 찾는다. "뭐 할 수 있어" 처럼 넓은 질문이면 `##` 제목들로 한눈에 요약한다.
2. 답 = **2~5줄** · 해요체 · 화면에서 누를 것을 순서대로 (예: "왼쪽 아래 내 이름 → 이 기기 알림"). 문서 문장을 길게 붙여 넣지 않는다.
3. 마지막 줄에 웹 링크 1개: `webUrl` + `#` + 그 섹션 제목의 slug (제목 소문자 · 공백 → `-` · 구두점 (`·` `?` `(` `)` 등) 삭제 · 한글 그대로). 예: `…/guide#비용` · `…/guide#claude-로-하기` · `…/guide#파일-찾기--올리기`. 맞는 섹션이 애매하면 `webUrl` 만.
4. Claude 로 바로 할 수 있는 일이면 문서의 "Claude 로 하기" 에서 "이렇게 말하면 돼요" 예시 1개를 붙인다. **실행은 사용자가 원할 때만** — 원하면 해당 스킬 (`briefing` · `task` · `wiki` · `file` · `meeting` · `cost`) 절차로 넘어간다.

## 예

"영수증은 어디서 올려?"
→ `getGuide` → "비용 › 영수증" 섹션 → "비용 → 영수증 탭 → **새 기록** 에서 사진이나 PDF 를 붙여요. 이미 있는 기록은 패널의 **증빙 추가**. Claude 에게 '11월 14일 회식 법카 12만 8천원' 처럼 말해도 기록돼요 (사진은 Claude 가 주는 링크에서). → https://hq.nodemill.ai/guide#영수증"

## 규칙

- 문서에 없는 기능 · 메뉴는 지어내지 않는다 — "사용법 문서에 없어요" 라고 말하고, 필요하면 관리자에게 물어보라고 한다.
- 비밀번호 · 계정 질문은 문서의 "계정" 섹션대로 Bitwarden 으로 안내한다 (hq 에는 없다).
- 권한 (관리자 전용) 이 걸린 일이면 그 사실을 한 줄로 알린다.
- `getGuide` 가 401 · 연결 오류면 "hq 연결이 끊겼다 — Claude Code 는 `/mcp` 에서, claude.ai 는 플러그인 Connectors 탭에서 hq 에 다시 로그인" 을 안내하고 멈춘다. 도구가 없다는 오류면 "hq 서버가 아직 이 기능 전 버전이에요" 라고 알리고 멈춘다.
- 결과 JSON · 문서 원문 전체를 그대로 붙이지 않는다.
