> 미팅 스킬 (`SKILL.md`) 의 갈래 파일. 경로 `references/…` 는 스킬 폴더 기준.

## 안건 추가 — "11/25 주간 미팅에 안건 추가해 — …" · "<날짜> <주제> 미팅 노트 만들어"

1. **대상**: `listEvents` 에서 그 미팅 일정 — 주간 = `{ from: 오늘, to: 오늘+7 }` 의 제목 `주간 미팅` 중 끝나지 않은 첫 것 (날짜를 말했으면 그날) · 주제 = 말한 날짜 하루. 대상 = `eventId` (일정의 `meeting` 이 있으면 `meetingId` 도 된다). 일정이 없으면 "회사 캘린더에 일정부터 잡을까요?" (`schedule` 스킬) — 일정 없이 가자고 하거나 `listEvents` 가 `UNAVAILABLE` 이면 `date` + `meetingTitle`.
2. **안건**: `title` · `proposerId` (기안 = 말한 사람 — `listMembers` 의 id · 생략 = 나) · `detail` (말에 담긴 배경 · 현재 상태 · 결정이 필요하면 선택지 A / B — 줄마다 한 항목 · 목적은 묻지 않는다) · `links` (언급된 태스크 키 `HQ-0057` · 로드맵 · 위키 · URL — `getTaskByKey` · `listRoadmaps` · `getWikiPage` 로 확인한 것만 · 로드맵 · 위키는 `hqUrl` · 못 찾으면 상세에 이름만).
3. `addMeetingAgenda { eventId | meetingId | date + meetingTitle, agenda }` — 노트가 있으면 다음 번호로 덧붙이고 (다른 사람이 쓴 행 · 블록 · 내용은 hq 가 그대로 둔다) 없으면 만들고 넣는다. `place-required` 면 `references/자리-규칙.md` 대로 묻고 다시.
4. `needsFill: true` (사내 노트를 방금 만들었다) 면 이어서 `references/준비.md` 3 ~ 5 로 지난 액션 · 넘어온 안건을 채운다.
5. **보고**: 미팅 제목 · 안건 번호 · hq 링크 (`https://hq.nodemill.ai/meetings?m=<meetingId>`) · (만들었으면) 자리.
