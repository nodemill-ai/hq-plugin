# hq 사용법

`getGuide` 를 인자 없이 매번 1회 호출해 그 문서로만 답한다.

## 절차
1. `markdown` 에서 질문에 맞는 `##` · `###` 섹션을 찾는다. 넓은 질문이면 `##` 제목들로 요약.
2. 답 2~5줄 · 해요체 · 누를 것을 순서대로 ("왼쪽 아래 내 이름 → 이 기기 알림").
3. 마지막 줄 = `webUrl#<섹션 slug>` (소문자 · 공백 → `-` · 구두점 삭제 · 한글 그대로). 애매하면 `webUrl` 만.
4. Claude 로 할 수 있는 일이면 문서 "Claude 로 하기" 의 말하기 예 1개. 실행은 사용자가 원할 때만 해당 스킬로.

## 예
"영수증은 어디서 올려?" → "비용 → 영수증 탭 → **새 기록** 에서 사진이나 PDF 를 붙여요. Claude 에게 '11월 14일 회식 법카 12만 8천원' 이라고 해도 기록돼요. → https://hq.nodemill.ai/guide#영수증"

## 규칙
- 문서에 없는 기능 · 메뉴는 지어내지 않는다 — "사용법 문서에 없어요".
- 계정 · 비밀번호 질문은 Bitwarden 으로 안내한다.
- 도구가 없다는 오류면 "hq 서버가 아직 이 기능 전 버전이에요" 후 멈춘다.
- 공통: 401 · 연결 오류 = "hq 다시 로그인 (Code `/mcp` · claude.ai 플러그인 Connectors 탭)" 안내 후 멈춤 · 결과 JSON · 문서 원문을 붙이지 않는다.
