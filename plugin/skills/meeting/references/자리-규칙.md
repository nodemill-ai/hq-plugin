> 미팅 스킬 (`SKILL.md`) 의 갈래 파일. 경로 `references/…` 는 스킬 폴더 기준.

## 자리 규칙

hq 는 미팅 위치 (`운영/미팅` · `고객사/<회사>/미팅`) 아래에서 **이름이 날짜 `YYYY-MM-DD` 로 시작하는 폴더를 미팅으로** (날짜 뒤는 `_` · `-` · 공백 아무거나 — `2026-11-18 주간 미팅` = `2026-11-18_주간-미팅`), **그 위 폴더는 전부 묶음 (주제 · 연 · 월)** 으로 읽는다 — 날짜 없는 폴더 · 미팅 위치 바로 아래 파일은 미팅이 아니다. 새 노트의 폴더는 hq 도구가 이 자리에 만든다 (커넥터로 폴더를 만들지 않는다).

| 종류 | 자리 | 예 |
|---|---|---|
| 주간 미팅 (사내) | `운영/미팅/주간-미팅/YYYY-MM/YYYY-MM-DD_주간-미팅/` | `운영/미팅/주간-미팅/2026-11/2026-11-18_주간-미팅/` |
| 주제가 있는 사내 미팅 | `운영/미팅/<주제>/YYYY-MM-DD_<제목>/` | `운영/미팅/다라상사-홈페이지-개발/2026-11-18_홈페이지-초기-스펙-논의/` |
| 그 밖의 사내 미팅 | `운영/미팅/YYYY/MM/YYYY-MM-DD_<제목>/` | `운영/미팅/2026/11/2026-11-03_hq-로드맵/` |
| 사외 | `고객사/<회사>/미팅/YYYY/MM/YYYY-MM-DD_<제목>/` | `고객사/가나금속/미팅/2026/11/2026-11-03_ERP-1차-시연/` |

- **주간 미팅** (일정 제목 `주간 미팅`) = hq 가 묻지 않고 `주간-미팅/YYYY-MM/` 아래 · `tags: [미팅, 주간]`.
- **자리 묻기**: 노트를 새로 만들 때 hq 가 INVALID `place-required` 를 돌려주면 그때만 묻는다 — `details.topics` (이미 있는 주제 폴더) · `details.customers` (hq 고객사) 와 위 사내 · 사외 정의를 보여 주고 사내 (기본) + 주제 (선택 — 있는 이름을 먼저 재사용 · 띄어쓰기만 다른 같은 주제는 hq 가 기존 폴더로) / 고객사 를 고르게 한 뒤 같은 호출에 `place` · `topic` / `company` 를 더해 다시. 주제 = 고객 일 · 프로젝트 같은 묶음 이름 — 에픽과 묶지 않는다. 고객사는 hq 고객사만 (`unknown-company` = 태스크의 고객사 칸으로 먼저 만들어야 한다고 안내) · 그 회사 폴더가 Drive 에 없으면 hq 가 만든다.
- 회의록 제목 = `YYYY-MM-DD <일정 제목>` (예 `2026-11-04 주간 미팅`) — hq 가 정한다. 같은 날 같은 제목의 일정은 노트 하나로 묶인다.
- 예전 미팅은 `미팅/` 바로 아래 · 옛 `YYYY/MM/` 에 있어도 hq 가 그대로 읽는다 — 옮기지 않는다. 옮기고 싶다고 하면 **Drive 앱에서 사용자가 끌어 옮기도록** 안내한다 (커넥터의 부모 변경은 공유 드라이브에서 권한 거부 · 폴더 id 가 그대로라 태스크 연결은 유지된다).
- 폴더 안: `회의록.md` (0~1개) + 자료 (이름은 `file` 스킬 규칙 `YYYYMMDD_주제_버전.확장자`, 사용자가 준 이름이 있으면 그대로). 종류 · 회사는 위치로 정해진다 — frontmatter 에 넣지 않는다.
